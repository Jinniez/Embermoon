# EMBERMOON Tarot

A dreamy, macaron-style random tarot draw page.

Draw a card, copy the result, and take it to your favourite AI for a reading. No interpretation is built in — the page only draws.

## Features

- 78 classic Rider-Waite cards, with true random draws
- Upright / reversed, decided independently for each card
- 13 spreads: Single Card, Yes / No, Past · Present · Future, Situation · Action · Outcome, Mind · Body · Spirit, You · Them · Relationship, Four Elements, Diamond, Small Cross, Five-Card, Horseshoe (7), Celtic Cross (10), Twelve Houses (12)
- Classic card artwork, 1-second reveal
- Click a card to focus it, click elsewhere to return
- Copy your draw in one tap: question + spread + card names + orientation
- Works as a single HTML file, no server needed

## How to use

1. Open https://jinniez.github.io/Embermoon-tarot/
2. Type your question
3. Pick a spread and tap Draw
4. Tap Copy, then paste it to an AI for your reading
